# Security Policy

## Supported Versions

This project does not currently have a formal release or version schedule.

Security fixes will generally be applied to the `main` branch. Other branches and forks may not receive security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately and responsibly.

This includes, but is not limited to, vulnerabilities that could:
- Allow unauthorised access to Bluesky accounts, or allow those accounts to be misused to publish, modify, or delete content.
- Allow unauthorised access to, modification of, or deletion of users' personal data or settings.
- Expose account credentials, passwords, session tokens, or other sensitive information.
- Cause harm to Bluesky, its infrastructure, or its users.

**Please do not disclose vulnerabilities publicly until they have been investigated and, where possible, fixed.**

Please report the vulnerability through either:
- [GitHub Security Advisories](https://github.com/Pikachannel/reply-bots/security/advisories/new)
- Email: pikachannel.dev@gmail.com
  - Subject: `[SECURITY] Brief description of the vulnerability`

When reporting a vulnerability, please include as much of the following information as possible:
- A description of the vulnerability.
- The potential security impact.
- The affected dependency or file, if known.
- Steps to reproduce the issue, if possible.

Please do not include:
- Account credentials, passwords, session tokens, or other sensitive information you may have access to through the vulnerability. Redact such information, where appropriate.

You do not need to provide a fully working exploit to report a suspected vulnerability.

Please avoid actions that could disrupt services, compromise other users' privacy, or access, modify, or delete data belonging to others while investigating a vulnerability.

## Response and Resolution

- **Acknowledgment:** I will aim to acknowledge your report within 7 calendar days.
- **Updates:** I will provide updates on the investigation and any planned fixes when possible. 
- **Timeline:** Resolution time depends on the severity and complexity of the issue.
- **Disclosure:** Please allow reasonable time for the vulnerability to be investigated and resolved before sharing any details publicly. Once fixed, relevant details may be disclosed publicly where appropriate.

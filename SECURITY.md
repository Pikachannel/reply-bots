# Security Policy

## Supported Versions

This project does not currently have a formal release or version schedule.

Security fixes will generally be applied to the main branch. Other branches and forks may not receive security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately and responsibly.

This includes, but is not limited to, vulnerabilities that could:
- Allow unauthorised access to Bluesky accounts or misuse of those accounts to publish, modify, or delete content.
- Allow unauthorised access to users' personal data or settings.
- Allow unauthorised modification or deletion of user data.
- Expose account credentials, passwords, session tokens, or other sensitive information.
- Cause harm to Bluesky, its infrastructure, or its users.

**Please do not disclose vulnerabilities publicly until they have been investigated and, where possible, fixed.**

Instead, either:
- Report it privately via the [Security](https://github.com/Pikachannel/reply-bots/security/advisories/new) section on the repository.
- Email: pikachannel.dev@gmail.com
  - Use the subject line: `[SECURITY] Brief description of the vulnerability`

When reporting a vulnerability, please include as much of the following information as possible:
- A description of the vulnerability.
- The potential security impact.
- The affected dependency or file, if known.
- Steps to reproduce the issue, if possible.

Please do not include:
- Account credentials, passwords, session tokens, or other sensitive information you may have access to through the vulnerability. Redact such information, where appropriate.

You do not need to provide a fully working exploit to report a suspected vulnerability.

## Response and Resolution

I will make a reasonable effort to acknowledge security reports within 7 calendar days of receiving them.

The reporter will receive updates on the investigation and any planned fixes when reasonably possible.

The time required to resolve a vulnerability will vary depending on its severity and complexity.

Please allow reasonable time to investigate and address the vulnerability before publicly releasing any details.

Once a vulnerability has been resolved, details regarding the incident will be publicly disclosed where appropriate.
